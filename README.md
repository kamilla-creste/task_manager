# Task Manager

A simple Python task management program.

The program allows the user to add, view, and delete tasks. Tasks are saved in a text file, so they remain available after the program is closed and started again.

## Features

- Add new tasks
- Display tasks with numbering
- Delete tasks
- Save tasks to a text file
- Load saved tasks when the program starts
- Handle attempts to delete tasks that do not exist
